# 装机宅 DLSS5 安装器

**0.2 Beta · Windows x64 · 游戏海报库、自动识别、A/B 插件切换**

[下载](https://github.com/smartLanny/dlss5-manager/releases) · [装机宅主页与教程](https://space.bilibili.com/941799) · [反馈](https://github.com/smartLanny/dlss5-manager/issues)

## 现在怎样使用

打开后自动查找 Steam / Epic 游戏。其他游戏点击“添加游戏”，选择 EXE。点击海报卡片的“安装 DLSS5”；程序自动识别运行方式，在支持的干净目录准备 ReShade、备份并部署插件。不再要求玩家填写 API、版本号或 SHA。

游戏详情可以指定 A 和 B 两个版本，退出游戏后点击切换。每个目标始终只有一份受管 addon，原始备份不会被第二次安装覆盖，已有配置和存档保持不动。恢复原版与撤销最近操作分开；错误时可直接从游戏详情反馈。

## 本发行包确切包含什么

公开包包含完整管理器，但 **当前没有可接入的授权公开 NR 成品来源，因此没有实际内置 0.3.3.4 / 0.4.2 Beta**。界面会如实显示未附插件，选择作者发布的 `.addon64` 或标准包即可导入；不会把空卡片称作“已集成二进制”。这两个版本是默认推荐与测试配置，不是永久版本上限。后续可导入任意版本。

完整离线发行能力已提供：发行方将已经批准分发的标准成品包放到独立分发目录，运行 `npm run pack:distribution -- <目录>`，再构建即可。工具要求推荐版和测试版都实际存在并校验成功；不会到 NR 私有仓库取源码或构建产物。详见 docs/DISTRIBUTION.md。

ReShade **6.8.0 full Add-on** 首次使用从固定官网地址获取、自动核验和提取，之后使用本地缓存。官方二进制不随公共安装器再分发。干净目录下 DX11/DX12 使用已验证来源的 `dxgi.dll`，OpenGL 使用 `opengl32.dll`；绝不覆盖未知代理、`d3d12.dll` 或系统文件。Vulkan 当前仅管理已有加载环境的 addon，不新建全局 Vulkan 注册。ReShade 支持这些 API 不代表 NR 已经支持，真实组件与游戏组合均待验证。

## 风险提醒与保护

在线、反作弊线索和不参与写入的未知代理现在是警告，不是一律禁用。玩家确认后可以进行 addon 测试；程序不会关闭、修改或绕过反作弊。相同游戏/插件/风险状态的确认可复用，新文件来源或风险变化会重新提醒。

**占用、写入时哈希变化、损坏更新包、损坏备份、不安全路径和未知代理覆盖仍停止。** 不能通过点“继续”强行操作。正常 A/B 切换属于可追踪的版本变更，不是哈希漂移，不会被误拦。

现有其他 addon 与代理保持原样。未验证的加载器可以仅更新 addon，但界面不会说运行效果已经验证。原始 addon 没有兼容性清单时标记本地测试，不猜版本支持所有 API。缺少 NR runtime 时明确提示组件未齐，不伪装为已可产生效果。

## 已实现

游戏海报墙、Steam/Epic/手动游戏发现、运行 EXE 与 API 自动检测、运行中游戏只读识别、版本自动读取、本地多版本导入、A/B/A 切换、幂等安装、官方 ReShade 获取与缓存、组合事务、恢复、保留设置、游戏隐藏/自定义海报、系统浏览器 B 站入口、统一脱敏反馈。

未实现：自动获取未公开的 NR 包、普通/未知 ReShade 的自动覆盖升级、Vulkan 全局环境部署、任意游戏参数配置编辑、GPU 实机渲染验证、管理器原子自更新、代码签名和正式发布者公钥接入。

## 开发与验收

```sh
npm ci
npm run check
npm test
npm run test:official
npm run test:ui
npm run build:win
```

测试使用合成游戏与 addon/runtime，不执行这些游戏文件。Windows 测试会实际下载并核对官方 ReShade，检验组合安装、A/B/A、无重复写入、恢复、设置保留，以及已打包 EXE 的安装/启动/卸载。图片演示不是游戏兼容性测试。

首次写入新格式数据会自动备份元数据；旧 0.1 不支持新记录，不要用旧程序继续管理同一目录。游戏回滚继续通过新管理器执行，不单独还原旧元数据。

## 外部修改与等待退出

已管理 addon 在外部换过版本时，先停止旧更新计划；游戏详情的安装流程可选择“保存当前 addon 为本地版本”，经一次确认，保留外部文件快照、上一受管版本和首次原始备份，再重新选择 A/B。该保存步骤只变更管理记录，不写游戏文件；不是忽略校验错误。加载器、runtime、缺失文件或损坏备份不能用此入口强行接管。

游戏正在运行时可以取消或等待退出后重新检查。等待不会结束进程或绕过文件锁；实际写入失败时停止并保留恢复入口。
