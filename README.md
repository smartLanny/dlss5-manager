## 现在怎样使用

打开后自动查找 Steam / Epic 游戏。其他游戏点击“添加游戏”，选择 EXE。点击海报卡片的“安装 DLSS5”；程序自动识别运行方式，在支持的干净目录准备 ReShade、备份并部署插件。不再要求玩家填写 API、版本号或 SHA。

游戏详情直接选择装机宅版本；退出游戏后点“切换到此版本”。每个目标始终只有一份受管 addon，原始备份不会被第二次安装覆盖，已导入版本会一直保留，方便比较不同版本效果。恢复原版与撤销最近操作都在游戏详情中；错误时可直接反馈。

## 本发行包确切包含什么

公开 Online 包必须内置真实的 0.3.3.4、0.4.1r2、0.4.3r3 成品；如果发行输入缺任一版本，发布校验会直接失败，不会用空卡片或其他版本冒充。玩家也可以导入以后新的 `.addon64` 或标准包，版本会自动加入列表。

完整离线发行能力已提供：发行方将已经批准分发的 addon、bridge、三套 runtime 放到独立分发目录，运行 `npm run build:offline -- --components "D:\\DLSS5-Full-Payload"` 即可。工具要求三个版本都实际存在并校验成功；不会到 NR 私有仓库取源码或构建产物。详见 docs/DISTRIBUTION.md。

ReShade **6.8.0 full Add-on** 首次使用从固定官网地址获取、自动核验和提取，之后使用本地缓存。官方二进制不随公共安装器再分发。干净目录下 DX11/DX12 使用已验证来源的 `dxgi.dll`，OpenGL 使用 `opengl32.dll`；绝不覆盖未知代理、`d3d12.dll` 或系统文件。Vulkan 当前仅管理已有加载环境的 addon，不新建全局 Vulkan 注册。ReShade 支持这些 API 不代表 NR 已经支持，真实组件与游戏组合均待验证。

## 风险提醒与保护

在线、反作弊线索和不参与写入的未知代理现在是警告，不是一律禁用。玩家确认后可以进行 addon 测试；程序不会关闭、修改或绕过反作弊。相同游戏/插件/风险状态的确认可复用，新文件来源或风险变化会重新提醒。

**占用、写入时哈希变化、损坏更新包、损坏备份、不安全路径和未知代理覆盖仍停止。** 不能通过点“继续”强行操作。版本切换属于可追踪的版本变更，不是哈希漂移，不会被误拦。

现有其他 addon 与代理保持原样。未验证的加载器可以仅更新 addon，但界面不会说运行效果已经验证。原始 addon 没有兼容性清单时标记本地测试，不猜版本支持所有 API。缺少 NR runtime 时明确提示组件未齐，不伪装为已可产生效果。

## 已实现

游戏海报墙、Steam/Epic/手动游戏发现、运行 EXE 与 API 自动检测、运行中游戏只读识别、版本自动读取、本地多版本导入、版本切换与保存、幂等安装、官方 ReShade 获取与缓存、GPU runtime 选择、组合事务、恢复、保留设置、游戏隐藏/自定义海报、系统浏览器 B 站入口、统一脱敏反馈。

未实现：自动获取未公开的 NR 包、普通/未知 ReShade 的自动覆盖升级、Vulkan 全局环境部署、任意游戏参数配置编辑、GPU 实机渲染验证、管理器原子自更新、代码签名和正式发布者公钥接入。

## 开发与验收

```sh
npm ci
npm run check
npm test
npm run test:official
npm run test:ui
npm run build:win
```

测试使用合成游戏与 addon/runtime，不执行这些游戏文件。Windows 测试会实际下载并核对官方 ReShade，检验 Steam 清单、真实海报缓存路径、bin/x64 主程序排序、三版本切换、无重复写入、恢复，以及已打包 EXE 的安装/启动/卸载。合成路径不是实际游戏兼容性测试。

首次写入新格式数据会自动备份元数据；旧 0.1 不支持新记录，不要用旧程序继续管理同一目录。游戏回滚继续通过新管理器执行，不单独还原旧元数据。

## 外部修改与等待退出

已管理 addon 在外部换过版本时，先停止旧更新计划；游戏详情的安装流程可选择“保存当前 addon 为本地版本”，经一次确认，保留外部文件快照、上一受管版本和首次原始备份，再重新选择版本。该保存步骤只变更管理记录，不写游戏文件；不是忽略校验错误。加载器、runtime、缺失文件或损坏备份不能用此入口强行接管。

游戏正在运行时可以取消或等待退出后重新检查。等待不会结束进程或绕过文件锁；实际写入失败时停止并保留恢复入口。

## 本轮 Beta 说明

本 Beta 修复丢失 EXE 后仍可卸载的问题；卸载时检查共用运行环境，不让其他插件跟着失效。反馈页可粘贴 F8 摘要、选择本次最多两个 ZIP，再保存为一个私下发送的反馈包。原始附件不会自动上传；实际采集配对仍需验证。详见 [生命周期与反馈改进](docs/LIFECYCLE-NEXT.md)。
