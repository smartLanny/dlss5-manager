第一次使用

打开软件 → 自动扫描游戏 → 选游戏 → 点安装。程序会准备运行环境、保存原文件并在失败时自动恢复。

当前主要面向 DX12 DLSS 游戏；其他 API 可以展示和反馈，但不会假装兼容。

管理器与插件分开更新

管理器更新从官方 Release 获取；群里有新的 addon 时，使用“导入新版本”，它会马上出现在游戏详情下拉框。

安全、版权与本地数据

备份和组件库保存在当前用户数据目录。卸载管理器不会删除游戏恢复数据。

未知图形插件会保持原样；真实文件锁会停止操作。不绕过反作弊，不删除存档、设置或其他模组。

请尊重 NR before SR 作者的版权及使用许可；管理器不修改 addon 内部实现。
