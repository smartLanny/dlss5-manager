第一次使用

添加游戏，导入装机宅发布的插件成品，点击安装。缺少支持的 ReShade 环境时自动从官网准备；已有其他模组时先提醒，不会盲目替换。

所有真实游戏与插件组合仍需测试。显示“已部署”不代表已经验证游戏内画面。

管理器与插件独立更新

群里发布新的插件，使用“导入更新”；管理器本身的更新从官方 Release 获取。

安全、版权与本地数据

备份和组件库保存在当前用户的数据目录。免安装版也使用这一目录，卸载管理器不会删除恢复数据。新版管理记录升级后，请继续使用新版恢复，不要单独回退元数据。

风险提示不等于兼容性保证；不绕过反作弊，不改系统 DLL。实际文件占用、损坏或备份失败时暂停写入。

请尊重 NR before SR 作者的版权及使用许可，不进行未经许可的逆向、复制或再分发。版权文字不是无法逆向的技术保证。管理器不修改 addon 内部实现。
