BUILT FOR PEACE OF MIND

上手很简单，边界也说清楚。

这是 NR before SR 插件管理器，不是通用显卡驱动或游戏破解工具。

01

先准备一次运行环境

按装机宅教程，为支持的单机游戏配置支持 Add-on 的 ReShade 和该版本所需的 NR runtime。Beta 不会盲目覆盖加载器。ReShade 官方二进制不随本安装器再分发。

02

之后在这里安装和换版本

添加游戏 EXE，确认图形 API，导入群里发布的 addon。检查变更清单后，管理器会先备份，再安装。

03

有问题，先恢复

游戏异常时先退出游戏，进入恢复中心撤销最近一次操作。不要反复覆盖，也不用猜该删哪些 DLL。

我们会做的安全检查

识别反作弊和高风险在线游戏；检查架构、代理冲突、文件占用和哈希；修改前备份；失败时尝试恢复。

“未发现阻断项”不等于“保证兼容”。未知游戏与未实测 API 均标记为待验证。

插件版权与来源

NR before SR 与本管理器独立。请尊重插件作者，不进行未经许可的逆向、反编译、复制或再分发。

版权声明是使用边界，不是无法逆向的技术保证。管理器不会改写或给插件添加隐蔽代码。
