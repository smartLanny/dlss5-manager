# 装机宅 DLSS5 安装器 0.2 Beta 候选

本轮针对 #13、#14 和 #10 的检查基础开发。是否已公开发布以 Release 页面为准；未打新标签时仅为开发分支的测试产物，不覆盖 0.1 Beta。

## 变化

同版本同哈希改为只校验；增加升级/降级/同版本文件变化标识；首次原始备份、已提交归属和同目录重复接管检查。新增组件清单 v2 与严格大小、管理器版本、依赖、冲突、恢复协议验证；v1 包和单 addon 保留。

新增“反馈与诊断”：七种问题类型、只读检查、脱敏报告预览、版本化反馈 ZIP、旧 ZIP、本地私有包、用户自行提交的 Manager 公开入口。未确认附件不会自动导出或上传。

ReShade 显示证据分级及官网入口。现有产品名/版本号不会被当作完整 Add-on 能力证明；尚未建立正式审定哈希目录，不捆绑官方二进制，不自动覆盖代理。#10 全新环境的一体化安装仍待后续实现。

## 升级数据提醒

旧状态只读打开不重写。首次导入组件 v2 后，保存旧元数据快照并将存储升级为 schema 2；0.1 无法执行新约束，会拒绝打开这一存储。原游戏备份不移动或重建，请用 0.2 进行恢复。不要只恢复旧 metadata 却保留新版本已经改变的游戏文件。

## 未承诺内容

真实 0.3.3.4、0.3.8beta、0.4.2beta 的游戏/API/反馈包兼容均待验证。本版不提供运行时采集、GPU 自动采集、自动发 Issue、代理 DLL 部署、正式发布者公钥或 Authenticode 签名，也未修改 NR 渲染实现。

## 验证

自动化使用合成文件，覆盖原有安全检查和事务、重复安装/升降级/原样恢复、v2 清单及签名、依赖复查、存储迁移、反馈 ZIP/隐私/确认边界。Windows 流程还检查真实 Electron UI、合成目录写入与撤销、安装包构建、NSIS 指定路径安装和卸载保留备份。结果以当前提交的 Actions 为准，不将合成测试冒充真机渲染验收。
