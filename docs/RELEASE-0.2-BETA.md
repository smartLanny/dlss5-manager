# 装机宅 DLSS5 0.2 Beta · 玩家流程重做

这次重做了首页和正常操作顺序：游戏海报库 → 安装 → A/B 切换 → 恢复/反馈。没有 API 下拉框、SHA 输入框和运行环境勾选表单。

## 下载

普通玩家使用 Setup.exe；Portable.exe 直接启动，不要求 Node.js。免安装版仍使用当前用户数据目录。安装器尚未配置 Windows 代码签名，仅从本仓库获取，不建议关闭安全软件。

## 新功能

- 自动发现 Steam/Epic，支持手动添加；海报缓存与本地海报选择。
- 自动确定 EXE/API；无法唯一确定时可识别正在运行的游戏，不让玩家猜 DX11/DX12/Vulkan。
- A/B 两个插件版本一键切换，原始备份和配置保留；同版本重复安装只校验。
- 缺少加载器的受支持干净目录，可自动从官网下载固定 ReShade 6.8.0 full Add-on，核验后部署，后续可复用缓存；与 addon 一起备份和回滚。
- 联机、反作弊线索和不涉及写入的未知代理改为警告。未知代理仍原样保留。占用、损坏文件、写入中变化和不安全覆盖不会强行继续。
- 反馈只需描述现象，游戏/插件/最近操作信息自动整理，预览后打开 GitHub 提交；不自动上传原始附件。

## 当前交付边界

**本公开 Release 尚未实际内置 NR 0.3.3.4 或 0.4.2 Beta 成品**：当前没有可供接入的授权公开成品地址，也没有读取 NR 私有仓库的构建文件。现有作者发布包/裸 addon 可直接导入，版本自动读取。发行方的完整组件预置接口已实现；两版本入口不是已捆绑二进制的证明。

ReShade 官方二进制不随公共包重新分发，首次需要访问官网，准备后可以离线复用。普通/未知 ReShade 的覆盖升级、Vulkan 全局部署仍未开放。真实游戏 NR 效果与硬件组合全部待验证；截图中海报库标注为界面演示，不能当作支持名单。

首次使用新格式会自动备份管理数据，不再弹出要求玩家理解元数据格式的表单。旧0.1无法继续管理这些新记录，请在新版本内执行游戏回滚。程序自身原子自更新不在本次范围。

## 验证

发布前必须通过 Node 安全/事务测试、固定官网 ReShade 获取与提取测试、真实 Windows Electron 自动识别/安装/A-B-A/回滚/设置保留、打包清单检查，以及 NSIS 安装、已安装程序启动、卸载保留备份测试。测试中的游戏和 NR 文件都是合成数据，不执行游戏或 NR 代码。

## 外部修改与等待退出

已管理 addon 在外部换过版本时，先停止旧更新计划；游戏详情的安装流程可选择“保存当前 addon 为本地版本”，经一次确认，保留外部文件快照、上一受管版本和首次原始备份，再重新选择 A/B。该保存步骤只变更管理记录，不写游戏文件；不是忽略校验错误。加载器、runtime、缺失文件或损坏备份不能用此入口强行接管。

游戏正在运行时可以取消或等待退出后重新检查。等待不会结束进程或绕过文件锁；实际写入失败时停止并保留恢复入口。
