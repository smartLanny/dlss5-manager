# 玩家安装生命周期与反馈改进（候选）

## 目标与当前交付

管理器 0.2.0-beta.3 候选，只修改独立 Manager；没有发布新 Release，也不修改组件实现。目标推荐版本调整为 0.3.3.4 与 0.4.1beta；实际成品绑定仍在 #13，不把空组件库当作已内置。

本轮实现：
- 卸载仅依赖有记录的目标目录、文件、备份和进程状态；不依赖已存在/有效的游戏 EXE 或当前 API。安装仍要求可靠识别。
- 卸载前有其他 addon、相关 ReShade 配置、自定义目录或不完整扫描时，保留可能共用的加载器。可能有其他 NR 使用者时也保留受管 NR runtime。保留理由与精确哈希进入卸载事务，不再随 NR 自动删除；恢复记录可追溯。无共用线索时仍能清理本工具新增的加载器。
- 原始安装的普通回滚如果会改变共用依赖，引导使用“卸载我们的插件”，而不是删除其他插件的宿主。
- 还原安装前已有 addon 不等于恢复游戏出厂状态。卸载确认会分别说明移除、还原、保留，完成信息不再笼统宣称“原版”。用户配置/存档不删。
- 默认 A/B 版本由主进程统一解析。0.4.1 的 r2/r3、0.4.2 或任意新版不能冒充精确目标版。显式 A/B 可继续绑定任意导入版；无槽位的已安装游戏沿用其当前包，不自动降级。
- 文件名中的 beta 前缀和 rN 修订保留。名称只是版本提示，不构成来源验证。
- 反馈入口统一，采集分开。支持可选粘贴 F8 完成摘要、选择本次最多两个 ZIP、预览后保存单个发送包。旧组件没有 F8 仍可反馈。F7 新核心与图像应同次配对，不混旧 F8；未验证的配对明确标注。

## 仍需完成（不以界面入口代替实现）

P0 #13：两版真实发行成品、实际 bridge/runtime/default-config 文件集合与分发来源；先在测试临时目录读取发行包清单，剔除源码/调试资料/安装脚本，不执行第三方脚本。当前标准包对 bridge 文件的支持仍待最小公开契约，不把文件名白名单无限扩展成任意 DLL 写入权限。

P0 #1/#3/#10：已确认身份的旧 NR 实例/重复加载，提供“备份并停用旧实例后安装”的事务计划。默认保留不相关 ReShade、RenoDX、ENB、DXVK、Streamline；不能凭两个 DLL 名字或所有 addon 的存在认定冲突。未知加载链保留并提供诊断，不盲删、不另建猜测代理链。

P0 #5：已被外部删除/替换的 runtime、插件运行后产生的配置/日志归属、跨目录依赖的清理收据与撤销。共用环境保留不代表已验证兼容；本轮不会自动删除这些新文件，也不宣称零残留。自动安装失败的恢复与第三方并发写入仍按原事务保护，无法恢复时保留备份。

P1 #14：获得可公开的实际反馈契约/样例后，验证精确 session、组件 binary 与 core-image 关系；只显示固定白名单诊断，不复制采集器或任何私有实现。大图像包和崩溃转储仍按独立隐私策略处理。上传直达须有维护者确认的端点、授权方式与保留策略，目前只生成本地文件。

## 兼容性影响与最小接口

无需修改 NR 仓库。Manager 只需要版本/渠道/API/文件角色及指纹/依赖/恢复说明；未来反馈只需要可公开的 capture ID、组件指纹、包角色及可选配对引用。不需要算法、源文件、内部路径或远程控制渲染。实际契约适配尚未完成，不把建议字段当作已存在字段。

| 管理器 | 目标组件 | API | 游戏类型 | 已知限制 | 回滚 |
|---|---|---|---|---|---|
| 0.2.0-beta.3 候选 | 0.3.3.4 / 0.4.1beta | 按真实组件声明；实际组合待验证 | Windows x64；单机优先，在线/反作弊告警 | 未绑定精确发行成品；共用宿主保留、未知代理不覆盖 | 上一事务、首次备份；卸载收据列出保留文件 |
| 同上 | 后续本地 addon / 包 | 同上，不按名称推断兼容 | 同上 | A/B 不限首发版本；运行中先退出 | 同一事务与原始备份 |
| 同上 | 支持 F8/F7 的组件 | 管理器收集与渲染 API 解耦 | 能进游戏用运行内采集，崩溃用离线资料 | 两 ZIP 的 session/构建配对未认证；大小限制存在 | 只读导入与本地导出，不改游戏 |

## 验证

本轮增加卸载/共用依赖/版本识别/反馈集合测试，并扩展实际 Electron Windows 流程：删除合成 EXE 后卸载、保留其他 addon 及依赖、撤销卸载、无共用环境的完整清理、F8 摘要脱敏与两附件导出。所有 NR/游戏文件均为合成样本，不执行，不代表真实游戏画面或 F8 格式验收。以 PR 最终 CI 结果为准。
