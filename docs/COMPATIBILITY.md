# 0.2.0-beta.2 兼容性影响

仅修改独立 Manager，不修改 NR 渲染源码或组件字节。玩家不再手工填写 API/哈希；文件与元数据验证仍在后台进行。检测到多个有效 API 或多个运行 EXE 时不盲猜，提供只读“识别运行中的游戏”；仍不能确定则不改文件。

| 管理器 | 目标组件 | API | 游戏类型 | 冲突与限制 | 回滚 |
|---|---|---|---|---|---|
| 0.2.0-beta.2 | 0.3.3.4 推荐版 | 按成品声明匹配，实际游戏组合待验证 | x64 游戏；离线单机优先 | 在线/反作弊/第三方代理提示后可作 addon 测试；未知代理不覆盖 | 更新快照；恢复首次原文件 |
| 同上 | 0.4.1beta 测试版 | 同上，待验证 | 同上 | 同上；A/B 不是运行中热切换 | A/B/A 与上次快照 |
| 同上 | 后续标准包/裸 addon | 标准包强制匹配声明；裸文件缺声明时提示本地试验，实际待验证 | 同上 | 不确定的运行方式不盲选；损坏文件/占用停止 | 同上 |
| 同上 | 官网 ReShade 6.8.0 full Add-on | 干净目录 DX11/DX12/OpenGL；Vulkan仅已有环境 | 先核验目标和图形模式 | 固定官网下载；精确哈希识别；不覆盖未知或多个代理 | 与 addon 同一事务；卸载只移除受管 loader |

公共发行的 NR 成品输入尚未提供，当前并不内置上述真实插件。ReShade 来源与解压已独立验证；合成目录安装测试不代表真实 NR 与游戏效果验收。

保留当前 ReShade.ini、其他配置、存档、第三方 shader 与插件。不做配置全量重置，不推测 NR 配置格式。若现有 AddonPath 指向特殊目录，当前只是提示已有环境未验证，不自动改掉它。

旧 0.1 不支持新的 loader/自动目标包记录，首次出现这些记录前自动备份元数据并提高状态格式版本。只使用新管理器恢复游戏，不独立还原旧 state.json。已有原始文件备份不会重建或删除。

## 外部修改与等待退出

已管理 addon 在外部换过版本时，先停止旧更新计划；游戏详情的安装流程可选择“保存当前 addon 为本地版本”，经一次确认，保留外部文件快照、上一受管版本和首次原始备份，再重新选择 A/B。该保存步骤只变更管理记录，不写游戏文件；不是忽略校验错误。加载器、runtime、缺失文件或损坏备份不能用此入口强行接管。

游戏正在运行时可以取消或等待退出后重新检查。等待不会结束进程或绕过文件锁；实际写入失败时停止并保留恢复入口。
