## 存储与已有 0.1 数据

只读打开不会修改 0.1 的 state 或备份。单 addon / v1 包继续兼容。首次保存带 v2 清单的包前，保存独立元数据快照，再将 state 的 schema 提升到 2，以防旧管理器忽略新安全约束。新管理器支持读取 schema 1 / 2；新旧元数据不会被宣传成任意可互换。用户仍在测试的 0.1 发布物不更新、不静默安装候选版。

## NR 最小接口与影响

组件方可选择提供公开清单 v2，或继续提供原有单文件/v1 包；不需要修改渲染算法。运行时反馈可选择提供 feedback-manifest.json，不要求 Manager 知道其内部采集逻辑。管理器不向 NR 添加版权字节、保护代码或构建参数，原始 addon 字节保持不变。

## 验证边界

自动化只执行管理器和合成文件，不执行测试 PE。签名测试用临时测试密钥；ReShade 能力测试用合成哈希目录，不代表真实官方版本已经审定。真实游戏启动、画面、性能、驱动以及三个实际组件包均需真机验收。
