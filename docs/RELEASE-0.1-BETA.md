# 装机宅 DLSS5 安装器 0.1 Beta

首个可运行的 Windows x64 独立管理器。以文件安全、中文易用界面和可恢复更新为先，不包含 NR before SR 私有源码或真实插件文件。

## 下载哪个

**Setup.exe** 为安装版，安装到当前用户，不要求预装 Node.js。**Portable.exe** 为免安装启动版。二者都把备份和版本库保存在当前用户的数据目录，便携版不是把所有数据写到 U 盘的完全便携模式。

`SHA256SUMS.txt` 提供两个程序的校验值，`RELEASE-CONTENTS.json` 提供版本、构建提交、包内容和组件边界。没有配置 Authenticode 签名，系统可能提示核验来源；只从本仓库发布页获取安装器，不建议关闭安全软件。

## 已实现

现代深色中文界面；Steam 扫描与手动 EXE 添加；候选 EXE 与 API 确认；反作弊、在线游戏和未知文件门禁；文件版本、架构、签名状态、SHA-256 与来源报告；安装前预览与完整备份；本地 addon 更新、版本切换、失败恢复尝试、重启后恢复、卸载回到最初状态；脱敏诊断；常驻装机宅 B 站入口。

预置 `0.3.3.4` 稳定版、`0.3.8beta` UI 调整版、`0.4.2beta` 色彩/效率强化版入口。也可以填写后续版本号，直接导入群内发布的新 addon，或导入标准更新包。

## 第一次使用

先按 [装机宅官方主页的教程](https://space.bilibili.com/941799) 配置目标单机游戏的 Add-on 运行环境。然后添加游戏，导入插件，确认 API、离线类型与变更清单，再点击备份安装。异常时先退出游戏，到恢复中心撤销最近一次操作。

## 重要边界

- 三个版本卡片是本地导入入口，**不是捆绑了三个真实插件**。本发行包不含 addon、NR runtime 或 ReShade；它们继续独立发布。
- Beta 不安装或覆盖图形代理 DLL，不为在线竞技目标自动安装，不提供任何反作弊绕过功能。
- 每个真实组件/API/游戏组合的运行兼容性均为“待验证”。自动化测试是合成文件测试，不是 NR 画面实测。
- 自更新目前是检查版本与打开官方发布页；不会后台替换管理器程序。正式发布者公钥尚未配置。已有 addon 的内部保护措施未检查，原始字节不修改。

## 验证与组成

发布流水线要求源文件语法检查、安全与事务测试、真实 Electron 界面测试、Windows 合成游戏目录安装/回滚、发行包内容检查，以及 NSIS 实际安装、已安装程序启动、卸载保留恢复数据全部成功。

详细范围见 [README](https://github.com/smartLanny/dlss5-manager#readme) 与 [兼容性矩阵](https://github.com/smartLanny/dlss5-manager/blob/release/beta-0.1/docs/COMPATIBILITY.md)。Beta 没有对所有游戏或意外断电场景提供保证。

管理器原创内容暂不授予开源许可，第三方许可证仍有效；NR 组件许可独立。版权与禁止未经授权分析的文字说明不是无法逆向的技术保证。
