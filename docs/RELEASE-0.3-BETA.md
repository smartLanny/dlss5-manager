# 装机宅 DLSS5 0.3 Beta · 小白一键安装

打开软件 → 自动扫描游戏 → 选游戏 → 点安装。

- 默认使用装机宅 `0.3.3.4` 稳定版；游戏详情还可以保存并切换 `0.2.0-beta.2`、`0.4.1r2`、`0.4.3r3`，也支持以后导入新的 addon。
- 自动准备对应显卡的运行环境和 ReShade Add-on 支持。
- 安装前先检查完整组件，安装时自动保存原文件；失败会自动恢复。
- 游戏详情内可以一键换版本、卸载装机宅插件或恢复安装前状态。
- RTX 40 与 RTX 20/30 运行环境仍是实验性 / 待验证；r3 没有宣称解决 RTX40 MFG #63。
- DX11、Vulkan、OpenGL 可以被识别和展示，但当前 NR before SR 兼容性仍待验证。

这是 Beta。真实游戏效果按游戏、显卡和现有模组分别验证；安装器通过了合成玩家路径和 Windows 安全事务测试，不把合成测试当作实际渲染承诺。
