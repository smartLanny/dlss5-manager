# 装机宅 DLSS5 一体化 Beta 使用说明

版本：`0.3.0-beta.1` · Windows x64

## 这版做了什么

- 安装器准备 `0.3.3.4`（默认稳定）、`0.4.1r2` 和 `0.4.3r3` 三个插件版本；启动时读取 Windows 显卡型号并自动选择对应运行环境。
- 支持自动扫描 Steam / Epic，也支持“添加游戏”后直接选择真实游戏 EXE；会自动识别游戏目录、运行文件和 DX11 / DX12。
- 首次安装 DX11 / DX12 游戏时，自动从 ReShade 官方固定地址下载、核验并缓存 6.8.0 Full Add-on 运行环境。
- 一次安装 NR addon、运行组件、桥接组件和配置；现有设置、存档和其他未接管文件保持不动。
- 每次替换已有受管文件都会在目标旁保留 `.bak` 副本；管理器的恢复记录也保存了同一份原始校验，可从“恢复记录”回滚。
- 游戏详情内直接切换并保存版本选择；异常时先退出游戏，再恢复最近一次操作。

## 安装方式

1. 推荐双击 `Zhuangjizhai-DLSS5-Manager-0.3.0-beta.1-Setup.exe`，按默认选项安装。
2. 不想安装到系统时，直接运行 `Zhuangjizhai-DLSS5-Manager-0.3.0-beta.1-Portable.exe`。
3. 第一次安装游戏组件需要联网获取 ReShade 官方文件；下载会做固定版本和 SHA-256 校验，成功后会在本机缓存，之后可离线复用。
4. 打开“我的游戏”：程序会自动查找 Steam / Epic、补充海报并识别真实运行程序；没找到时点“添加游戏”，选游戏实际运行的 `.exe`。
5. 点游戏卡片的“安装 DLSS5”，确认提示后安装。程序会自动按 RTX 50、RTX 40 或 RTX 20/30 选择运行环境，不需要手动填写 API、版本号或哈希。

## 出现提醒时怎么处理

- “未能确认显卡型号”：本版只自动安装 RTX 40 / RTX 50 组件；不要强行选择另一套，先确认驱动和设备是否正常。
- “发现其他图形加载器”：未知的 `dxgi.dll`、`d3d12.dll` 等文件会保留，避免误删其他模组或系统相关文件。需要处理时先人工确认来源，并保留副本。
- “反作弊 / 在线游戏提醒”：本工具不会关闭、绕过或修改反作弊；只在游戏和平台允许的环境中测试。
- “游戏仍在运行 / 文件被占用”：完全退出游戏、启动器和覆盖层后重试。
- 安装不理想：退出游戏，在游戏详情中选择“恢复上次操作”“卸载装机宅插件”或“恢复安装前状态”。

## 兼容性边界

当前随包 NR 组件以 DX12 为目标，真实游戏效果仍需逐款验证；安装器显示“已部署”不等于已经验证画面效果。Vulkan 不会自动创建全局加载环境。管理器不会覆盖未知代理、系统 DLL、反作弊文件，也不会自动删除无法确认归属的文件。

## 校验

请同时保留 `SHA256SUMS.txt`。下载完成后核对 Setup 或 Portable 的 SHA-256；两个文件的大小不同是正常的。

## 反馈

安装器内的“反馈问题”会先生成脱敏预览，不会自动上传。教程、公告和更新动态见装机宅 B 站主页：<https://space.bilibili.com/941799>。
