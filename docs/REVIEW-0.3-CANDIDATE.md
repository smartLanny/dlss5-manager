# Manager 0.3.0-beta.1 候选审查

首次冻结范围：`8f21ff3afc14297d7ec520cd5e0af185815b2669..3420852d602d5332616eab2f37d24ff362dd0095`，聚合 PR #16、#21 和启动设置接入。一次并行审查分别检查生命周期安全与功能合同；修复后仅针对改动复验。

## 发现与处理

| 级别 | 触发场景 | 修后行为 |
|---|---|---|
| P1 | 应用覆盖期间全局继承值改变，恢复被误判失败 | 写前完整 CAS 保持严格；仅恢复非显式变化项时接受实际的新继承状态，保存真实回读；外部显式值仍阻止恢复 |
| P1 | 原 RTX40 配置潜伏 generatedOnlyDebug，保存固定模式后自动启动激活它 | 有实际变化时要求手动预览确认，启动自动处理不会激活；不擅自改掉原 debug 键 |
| P1 | 只有 SR/FG 归属而未安装 NR 时，运行观察换到另一 EXE | 已有安装或启动设置时均禁止迁移目标；同路径大小写变化保留原绑定 |
| P2 | 工具专属 profile 后来增加范围外显式键，自身覆盖无法恢复 | 保留 profile 和外部键，只删除本工具目标覆盖，严格核对保留身份 |

同时修正高级详情把 EXE 导入线索写成实际运行方式的问题。API 待确认时点击安装进入选择详情；手动 DX12 与静态 DX11 线索分别显示。

修后针对复验没有残留 P0/P1/P2 finding。结论为可合并的配置管理增量，仍以最终提交的 CI 和构建为门槛；不能据此宣布真实游戏兼容性通过。

## 合并顺序

PR #21 的修正提交 `1a1c5e9` 已解决只读编译器两项 P2，本身可以独立合入；它不能作为 SR/FG writer 已交付的结论。PR #23 已包含该提交以及 PR #16 的 `224232f`。

推荐审完并合入最终 PR #23，再将 PR #21 与 #16 标记为已包含后关闭。若先单合 #21，也只应使用现有祖先关系继续合 #23，避免重复 cherry-pick 同一功能。本批不自动合 main、不创建发布标签、不覆盖已有 release。
